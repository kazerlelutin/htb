# Security policy / Politique de sécurité

## Reporting a vulnerability / Signaler une vulnérabilité

Please do **not** open a public GitHub issue for a suspected vulnerability.
Send a private report to [b@bouteiller.contact](mailto:b@bouteiller.contact)
with `HTB security` in the subject instead.

Merci de **ne pas** ouvrir d’issue GitHub publique pour une vulnérabilité
présumée. Envoyez plutôt un rapport privé à
[b@bouteiller.contact](mailto:b@bouteiller.contact), avec `HTB security` dans
l’objet.

Include the affected version or commit, a clear description, steps to
reproduce or a proof of concept, the potential impact, and any suggested
mitigation. Do not include credentials, access tokens, or personal data.

Indiquez la version ou le commit concerné, une description claire, des étapes
de reproduction ou une preuve de concept, l’impact potentiel et, si possible,
une mesure de correction. N’envoyez ni identifiants, ni jetons d’accès, ni
données personnelles.

## What happens next / Suite du traitement

We will acknowledge receipt within five business days, assess the report
privately, and keep you informed of material progress. We will agree on a
disclosure timeline before publishing details or a fix.

Nous accusons réception sous cinq jours ouvrés, évaluons le rapport de manière
privée et vous tenons informé·e des avancées importantes. Le calendrier de
divulgation est convenu avant toute publication de détail ou de correctif.

This policy covers the HTB source repository, published CLI binaries, the
hosted service at `htboard.xyz`, and the documented API and MCP endpoint.

Cette politique couvre le dépôt source HTB, les binaires CLI publiés, le
service hébergé `htboard.xyz`, ainsi que l’API et le point d’accès MCP
documentés.
